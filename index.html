Recent Corporate Actions Not Price-Adjusted

      ▲
    

    

      
Splits and bonuses ARE back-adjusted automatically and don't appear here. These are other corporate actions (demergers, NCRPS bonuses, capital reductions, etc.) from the last ~370 days that cause a real price discontinuity NSE doesn't publish a clean adjustment ratio for — SMA, 52W high/low, ADR, and change% may look distorted for these stocks until the affected window rolls past the ex-date.

      
Use the button to correct these prices from TradingView's already-adjusted history. Corrected events are saved to reference-data/DemergerAdjustments.csv, re-applied on every server start and removed from this list; anything TradingView can't confirm stays listed. TradingView is only contacted when you click — it must be running with --remote-debugging-port=9222 and have a chart open (your chart's symbol is restored afterwards).

      

        
        
      

      

    

  

  

    

      
Price Adjustments Applied

      ▲
    

    

      
Every stock whose historical prices were adjusted so an ex-date doesn't show up as a fake crash: splits and bonuses (ratio from NSE's corporate-actions feed) and demergers (factor derived from TradingView — see the section above). Factor is what prices before the ex-date were multiplied by. Dividends are not adjusted. Stocks no longer trading, and events older than the price history the dashboard keeps, aren't listed.

      
Use the button to check these against what TradingView shows: our daily closes are compared with TradingView's over their whole shared history, and any stock that differs is flagged. Read-only — no price is changed. TradingView Desktop must be running with --remote-debugging-port=9222 and have a chart open (your chart's symbol is restored afterwards). The first run takes about five minutes for ~200 stocks (it loads about two years of TradingView history for each); later runs only check what is still listed. Differences are explained where possible, e.g. TradingView adjusting for a rights issue that isn't in the corporate-actions data. If TradingView's own "adjust for dividends" setting is on, it shows up as small steady differences.

      
This list is a to-do queue: a stock that matches TradingView is removed from it and only returns when it gets a new or changed adjustment. Stocks with a difference stay until they match, and the button re-checks only the stocks still listed.

      

        
        
      

      

        
        
      

      

      

    

  

  

    

      
Full Price Verification (all stocks vs TradingView) 

      ▲
    

    

      
Checks every stock the dashboard holds — not only the price-adjusted ones above — against TradingView: each stock's daily closes are compared with TradingView's over their whole shared history (about 2 years) and graded match / minor / major. Run it now and then to make sure our prices haven't drifted from what you see on TradingView. Read-only — no price is changed. When it finishes it writes a report (a Markdown summary plus a CSV with one row per stock) to NSE_DATA/verification-reports/ for analysis, including what changed since the previous full run.

      
TradingView Desktop must be running with --remote-debugging-port=9222 and a chart open.  While it runs the chart flips through every stock, so leave TradingView alone, keep its window open and the PC awake. You can Stop at any time (progress is saved) and Resume later, as long as the data hasn't been refreshed in between.
